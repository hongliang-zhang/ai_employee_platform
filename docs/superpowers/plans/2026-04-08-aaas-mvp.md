# Agent as a Service MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the AaaS MVP: users can create a Telegram-accessible AI agent, chat through e2b sandboxes, and keep conversation history durable across sandbox restarts.

**Architecture:** A pnpm monorepo with four workspaces: `packages/backend`, `packages/agent-sdk`, `packages/dashboard`, and `agents/hello-agent`. `backend` is one Node.js process exposing `internal-api` on port 3001 for the dashboard and `gateway-api` on port 3002 for sandboxes. Sandboxes are stateless: PostgreSQL stores the canonical message history and `backend` proxies all LLM calls.

**Tech Stack:** Node.js 20, TypeScript 5, pnpm workspaces, Express 4, PostgreSQL 16, `pg`, `jsonwebtoken`, `@e2b/code-interpreter`, Next.js 14, Vitest, `msw`, `supertest`

---

## Critical Constraints

- `GATEWAY_URL` **must** be publicly reachable from e2b sandboxes via HTTPS. `localhost` and docker service names are not valid for real sandbox traffic.
- Do **not** use a placeholder migration for `agent_types.template_id`. Build `hello-agent`, then seed/update `agent_types` with a repeatable script.
- `routeMessage()` must return `{ conversationId, reply }`. Do **not** stash reply text in shared mutable state.
- `tsconfig.base.json` must **not** define `rootDir` or `outDir`; each package owns its own build output.
- Dashboard `/api/*` routes must validate the session cookie; page-only middleware is insufficient.
- Docker builds must use the **monorepo root as build context**.

- [ ] **Step 2: Write the initial migration**

`packages/backend/migrations/001_initial_schema.sql`:
```sql
CREATE EXTENSION IF NOT EXISTS pgcrypto;

CREATE TABLE IF NOT EXISTS agent_types (
  id               TEXT PRIMARY KEY DEFAULT gen_random_uuid(),
  name             TEXT NOT NULL UNIQUE,
  template_id      TEXT NOT NULL,
  port             INTEGER NOT NULL,
  idle_timeout_ms  INTEGER NOT NULL DEFAULT 300000,
  created_at       TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE IF NOT EXISTS agents (
  id             TEXT PRIMARY KEY DEFAULT gen_random_uuid(),
  agent_type_id  TEXT NOT NULL REFERENCES agent_types(id),
  name           TEXT NOT NULL,
  status         TEXT NOT NULL DEFAULT 'active',
  created_at     TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE IF NOT EXISTS im_configs (
  id               TEXT PRIMARY KEY DEFAULT gen_random_uuid(),
  agent_id         TEXT NOT NULL REFERENCES agents(id),
  platform         TEXT NOT NULL DEFAULT 'telegram',
  bot_token_enc    TEXT NOT NULL,
  status           TEXT NOT NULL DEFAULT 'active',
  created_at       TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE IF NOT EXISTS conversations (
  id                   TEXT PRIMARY KEY DEFAULT gen_random_uuid(),
  agent_id             TEXT NOT NULL REFERENCES agents(id),
  channel_key          TEXT NOT NULL,
  external_chat_id     TEXT NOT NULL,
  external_thread_key  TEXT NOT NULL DEFAULT '',
  created_at           TIMESTAMPTZ NOT NULL DEFAULT now(),
  last_message_at      TIMESTAMPTZ,
  UNIQUE (channel_key, external_chat_id, external_thread_key)
);

CREATE TABLE IF NOT EXISTS messages (
  id                   TEXT PRIMARY KEY DEFAULT gen_random_uuid(),
  conversation_id      TEXT NOT NULL REFERENCES conversations(id),
  role                 TEXT NOT NULL,
  content_json         JSONB NOT NULL,
  source               TEXT NOT NULL,
  external_message_id  TEXT,
  metadata_json        JSONB NOT NULL DEFAULT '{}',
  created_at           TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX IF NOT EXISTS messages_conversation_created_idx
  ON messages (conversation_id, created_at, id);

CREATE TABLE IF NOT EXISTS inbound_jobs (
  id                   TEXT PRIMARY KEY DEFAULT gen_random_uuid(),
  channel_key          TEXT NOT NULL,
  external_message_id  TEXT NOT NULL,
  conversation_id      TEXT NOT NULL REFERENCES conversations(id),
  status               TEXT NOT NULL DEFAULT 'pending',
  received_at          TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (channel_key, external_message_id)
);
```
